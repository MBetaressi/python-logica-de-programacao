# 🐍 Estudos de Python — Curso em Vídeo

Repositório destinado ao armazenamento dos exercícios, desafios e projetos desenvolvidos durante meus estudos de **Python** através do curso do **Curso em Vídeo**, com Gustavo Guanabara.

## 📚 Conteúdos estudados

Ao longo do curso, este repositório reúne exercícios relacionados a:

* 🖥️ Fundamentos da linguagem Python
* 🔢 Variáveis, tipos de dados e operadores
* 🔀 Estruturas condicionais
* 🔁 Estruturas de repetição
* 📋 Tuplas, listas e dicionários
* 🔧 Funções
* 📦 Módulos e pacotes
* 📁 Manipulação de arquivos
* 🧩 Programação Orientada a Objetos
* 🏗️ Exercícios e pequenos projetos práticos

## 🎯 Objetivo

Utilizar este repositório como forma de **praticar Python, consolidar os conceitos aprendidos e acompanhar minha evolução na programação**.

Os códigos aqui representam parte da minha jornada de aprendizado e serão atualizados conforme novos conteúdos e exercícios forem concluídos.
